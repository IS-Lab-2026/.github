# College of Science and Technology (CST) — Information Systems (IS) Year 2 (2026)
## 🚀 Java Project Hub

Welcome to the official GitHub organization for **CST Information Systems Year 2 (Class of 2026)**. This shared space is dedicated to our Object-Oriented Programming (OOP) journey, software engineering collaborations, and practical Java development.

---

### 📂 Organization Structure

Our repositories are organized to keep coursework, group projects, and lab assignments clearly separated:

* **`java-labs-2026`** — Weekly lab exercises, syntax practice, and core Java assignments (Collections, Exception Handling, I/O).
* **`is-group-projects`** — Major end-of-semester Java applications, featuring database integrations and GUI systems.
* **`course-resources`** — Lecture notes, code templates, and configuration guides for our environment.

---

### 🛠️ Tech Stack & Tools

We standardize our environment to ensure code builds flawlessly across all student machines:
* **Language:** Java SE 17 / 21 (LTS)
* **Build Tools:** Maven / Gradle
* **Database:** MySQL / PostgreSQL (for JDBC projects)
* **IDE Support:** IntelliJ IDEA / Eclipse / VS Code

---

### 🤝 Contribution & Collaboration Rules

To maintain high-quality code and simulate a professional software engineering environment, all members must follow these rules:

1. **Feature Branching:** Never push directly to the `main` branch. Always create a descriptive branch:
   ```bash
   git checkout -b feature/student-name-assignment1
   ```
2. **Pull Requests (PRs):** Submit a PR for reviews. At least one classmate or class representative must review and approve your code before merging.
3. **Commit Messages:** Keep your commits clear and actionable:
   ```text
   feat: implement student registration logic using JDBC
   fix: resolve NullPointerException in database connection string
   ```

---

### 📝 Academic Integrity Notice

This is a public, collaborative space meant for learning, peer review, and project management. 
* **Do your own work:** Sharing boilerplate code or libraries is encouraged, but outright copying assignments defeats the purpose of learning.
* **Protect your grades:** Please adhere strictly to the CST academic honesty guidelines regarding plagiarism.
